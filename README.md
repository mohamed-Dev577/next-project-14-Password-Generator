# 🔐 Password Generator | مولّد كلمات المرور

تطبيق ويب تفاعلي لتوليد كلمات مرور عشوائية باستخدام **Next.js وReact**، مع واجهة بسيطة تتيح للمستخدم إنشاء كلمة مرور جديدة بضغطة زر واحدة.

يهدف المشروع إلى تطبيق مفاهيم React الأساسية والتعامل مع النصوص والأرقام العشوائية والحلقات البرمجية وإدارة الحالة داخل تطبيق Next.js.

---

## 📌 نبذة عن المشروع

يتيح **Password Generator** إنشاء كلمات مرور عشوائية مكوّنة من 10 أحرف، باستخدام مجموعة متنوعة من الأحرف الإنجليزية الكبيرة والصغيرة والأرقام والرموز.

تم تطوير المشروع كتطبيق عملي لتدريب المهارات الأساسية في تطوير واجهات المستخدم باستخدام React وNext.js، مع التركيز على كتابة منطق برمجي واضح وتفاعلي.

## ✨ المميزات

* 🔐 توليد كلمات مرور عشوائية بضغطة زر.
* 🔄 إنشاء كلمة مرور جديدة عند كل عملية توليد.
* 🔠 دعم الأحرف الإنجليزية الكبيرة والصغيرة.
* 🔢 تضمين الأرقام ضمن مجموعة الأحرف المتاحة.
* 🔣 استخدام مجموعة من الرموز الخاصة.
* ⚡ تحديث كلمة المرور وعرضها مباشرة باستخدام React State.
* 📱 بنية بسيطة قابلة للتطوير وإضافة المزيد من الخصائص مستقبلًا.

## 🛠️ التقنيات المستخدمة

| التقنية                  | الاستخدام                                              |
| ------------------------ | ------------------------------------------------------ |
| Next.js                  | بناء التطبيق وتنظيم مكوناته                            |
| React                    | إنشاء واجهة المستخدم التفاعلية                         |
| JavaScript               | تنفيذ منطق توليد كلمات المرور                          |
| React Hooks — `useState` | إدارة كلمة المرور المعروضة وتحديثها                    |
| `Math.random()`          | توليد قيم عشوائية لاختيار الأحرف                       |
| `Math.floor()`           | تحويل القيم إلى أعداد صحيحة مناسبة لتحديد مواقع الأحرف |
| JSX                      | بناء عناصر واجهة المستخدم                              |

## ⚙️ آلية العمل

يعتمد التطبيق على مجموعة من الخطوات البرمجية:

1. تحديد مجموعة الأحرف والأرقام والرموز المتاحة.
2. تهيئة متغير فارغ لتجميع كلمة المرور الجديدة.
3. تكرار عملية اختيار الأحرف العشوائية عشر مرات.
4. تحديد موقع عشوائي داخل مجموعة الأحرف في كل تكرار.
5. إضافة الحرف المختار إلى كلمة المرور الجاري تكوينها.
6. تحديث حالة React باستخدام `setPassword`.
7. عرض كلمة المرور الجديدة مباشرة داخل الصفحة.

## 🎯 المهارات التي يطبّقها المشروع

* إدارة الحالة باستخدام `useState`.
* إنشاء الدوال والتعامل مع أحداث النقر.
* استخدام حلقات `for`.
* التعامل مع النصوص وخصائصها.
* الوصول إلى الأحرف باستخدام الفهرسة `String Indexing`.
* استخدام `Math.random()` و`Math.floor()`.
* تجميع النصوص وتحديث قيم المتغيرات.
* ربط منطق JavaScript بعناصر واجهة المستخدم باستخدام JSX.

## 🔒 ملاحظة أمنية

هذا المشروع تعليمي، ويستخدم `Math.random()` لاختيار الأحرف. لذلك، لا يُنصح بالاعتماد على النسخة الحالية لإنشاء كلمات مرور للحسابات المهمة.

عند تطوير إصدار للاستخدام الفعلي، ينبغي استخدام مصدر عشوائية آمن تشفيريًا، مثل `crypto.getRandomValues()`، مع مراعاة متطلبات الأمان المناسبة للتطبيق.
